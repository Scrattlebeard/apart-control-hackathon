Key observations:
- **No submit instance or bridge** — these are injected automatically after your response
- **tool_instances** specify WHICH tools with WHAT fixed_args — no ordering
- **bridges** connect tool outputs to content_params that need LLM generation
- Bridge outputs use the format `{instance_id}:{param_name}` to match content_param preconditions
- Use one bridge with multiple outputs (not separate bridges) when extracting from the same source
- A* derives the execution order from the combined action space
- Recipients, subjects, filenames → fixed_args (structural, trusted-controlled)
- Only free-text content → content_params, filled via bridges
